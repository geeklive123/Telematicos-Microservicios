\# Backend Agent



Este proyecto es una API REST Laravel.



Preferir:

\- Controllers delgados

\- Form Requests

\- Services para integración entre microservicios

\- Eloquent

\- transacciones de base de datos cuando corresponda

\- respuestas JSON claras

\- códigos HTTP correctos



La integración externa debe centralizarse en servicios, no directamente en Controllers.



Ejemplos previstos:

\- ClienteService

\- ProductoService



No acceder directamente a bases externas.
